The Idea

The Bridge is an internal merchandising intelligence tool built for Waterworks' tech support team. It turns a slow, manual data-pulling process into an on-demand dashboard — allowing any team member to look up a style or collection and instantly see revenue, units, margins, and channel performance across 2023–2025.

Internal Tooling Data Visualization Waterworks HTML / JS No-Code Deploy
The Problem

The tech support team regularly needed sales data — unit counts, revenue trends, margin visibility — to troubleshoot customer issues and assess the scope of emerging problems. There was no self-serve way to get this information. Every request routed through the product management team, creating a recurring ad hoc reporting burden and slowing down the team's response time.

  • No self-serve access to style-level performance data
  • Repeated manual requests routed through product team
  • Slow turnaround on scope assessments during live issues
  • No way to compare channel, finish, or year-over-year trends quickly
The Constraint

The most obvious solution — a third-party BI tool or cloud dashboard — was immediately off the table. Waterworks' sales data is sensitive and proprietary. Putting it on an external platform without a formal procurement and security review wasn't an option.

Design Constraint The tool needed to run entirely client-side — no servers, no external APIs, no data transmission. Everything had to process locally in the browser, making it functionally equivalent to opening a spreadsheet, but purpose-built and far more usable.
The Solution

The Bridge is a single HTML file that runs in any browser with no installation required. A user exports a CSV from the company's internal sales system, drags it into the tool, and immediately has access to a full performance dashboard. All data processing happens in the browser — nothing ever leaves the machine.

  • Style & collection search with autocomplete across 6-digit style numbers and collection names
  • Multi-style comparison — tag multiple styles to view their combined performance in one view
  • Year-over-year charts for revenue and units shipped (2023–2025)
  • Gross margin visibility calculated live from revenue and COGS in the export
  • Channel breakdown showing Residential, Commercial, and Other revenue share
  • Metal finish breakdown for finish-level performance analysis
  • Cascading hierarchy filters — drill from LOB → Group → Class → Type → Subtype in the sidebar
Try It

A working demo with sample data. Search "Harlow" or "Sutton", or drill down by category using the sidebar filters.

Measuring Impact
  • Reduction in ad hoc data requests to the product team
  • Time-to-answer for scope assessments during live issues
  • Adoption rate among tech support team members
  • Qualitative feedback on decision confidence during troubleshooting
